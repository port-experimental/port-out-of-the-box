# terraform-port-scorecard-root-module

Composes the `terraform-port-scorecard` child module and configures the Port provider to deploy a production readiness scorecard on the `service` blueprint.

## Architecture

```text
Pipeline environment variables
  └── Port provider
        └── terraform-port-scorecard child module
              └── Production readiness scorecard
                    ├── Bronze: has an owning team
                    ├── Silver: has a runbook URL
                    └── Gold: has a repository URL
```

The root owns provider configuration and the scorecard rule definitions. The child module owns only the `port_scorecard` resource.

## Prerequisites

- Terraform >= 1.16
- `port-labs/port-labs` provider >= 2.32.2
- A `service` blueprint with `runbook_url` and `url` properties
- `PORT_CLIENT_ID` and `PORT_CLIENT_SECRET` available as protected pipeline environment variables

## Configuration

The scorecard rules are supplied from `local.production_readiness.rules` in `data.tf`:

```hcl
module "production_readiness_scorecard" {
  source = "git::https://github.com/port-experimental/terraform-port-scorecard.git?ref=v1.0.0"

  identifier     = var.identifier
  title          = var.title
  port_blueprint = var.port_blueprint
  rules          = local.production_readiness.rules
}
```

Each rule sets an `identifier`, `title`, `level`, and a `query` whose `conditions` are JSON-encoded with `jsonencode()`. Rules use Port's default levels: entities start at `Basic` and progress through `Bronze`, `Silver`, and `Gold` as they pass each level's rules.

To add a rule, append an entry to `local.production_readiness.rules`:

```hcl
{
  identifier = "has_language"
  title      = "Has a language set"
  level      = "Silver"
  query = {
    combinator = "and"
    conditions = [
      jsonencode({
        property = "language"
        operator = "isNotEmpty"
      }),
    ]
  }
}
```

## Inputs

- `identifier` — Scorecard identifier. Defaults to `tf_production_readiness`.
- `title` — Scorecard title. Defaults to `Production Readiness Generated by Terraform`.
- `port_blueprint` — Blueprint the scorecard evaluates. Defaults to `service`.

`PORT_CLIENT_ID` and `PORT_CLIENT_SECRET` authenticate the Port provider. Set them through the pipeline environment; do not use `.tfvars` files or commit credentials.

## Outputs

- `scorecard_identifier` — Configured scorecard identifier.
- `scorecard_title` — Scorecard title displayed in Port.
- `scorecard_rules` — Rules applied by the scorecard.
